# CofreSeguro

Gerenciador de senhas desenvolvido para o Projeto Integrador 4 (Cibersegurança em Programação Segura) da PUC-Campinas.

As credenciais ficam guardadas de forma cifrada, protegidas por uma senha-mestra que não é armazenada em nenhum lugar.
